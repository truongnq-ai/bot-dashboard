# Dashboard Metrics Components

This folder contains components used for displaying dashboard metrics and statistics.

**Note:** Despite the folder name "ecommerce", these components are used for the admin dashboard's main metrics display (not e-commerce functionality).

## Components

- `EcommerceMetrics.tsx` - Main metrics cards
- `MonthlySalesChart.tsx` - Monthly sales chart
- `MonthlyTarget.tsx` - Monthly target display
- `StatisticsChart.tsx` - Statistics chart
- `RecentOrders.tsx` - Recent orders list
- `DemographicCard.tsx` - Demographic information card
- `CountryMap.tsx` - Country map visualization (used in DemographicCard)

## Usage

All components are used in `/dashboard` page.
